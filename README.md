# Activité Pratique N°5 — Agentic AI et MCP (LangChain & LangGraph)

## Installation

```bash
uv sync
cp .env.example .env
```

## Structure du projet

- `notebooks/part_a_langchain.ipynb` — Partie A : Agents LangChain, mémoire, tools, middlewares, RAG agentique
- `notebooks/part_b1_langgraph_bases.ipynb` — Partie B1 : Bases de LangGraph (graphes, routage, boucles, HITL, MAS)
- `part_b2_rag/` — Partie B2 : Chatbot Agentic RAG (LangGraph Studio + Streamlit)
- `part_c_mcp/` — Partie C : Serveur MCP (`streamable-http`), client LangChain/LangGraph et n8n
- `part_d_sav/` — Partie D : Travail de synthèse (Orchestrateur LangGraph + `agent_documentaire` via MCP + `agent_garantie`)
